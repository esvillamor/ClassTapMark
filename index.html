Help & EULA

Version: v1.2 · Storage: Browser localStorage · Works offline · SF2‑Ready

Overview

ClassTapMark is an offline-first attendance manager designed for teachers. It supports class & student management, fast attendance marking, Non‑School Days (NSD), Class Day Notes (CDN), monthly aggregates, CSV import/export, and quick SF2 PDF generation. All data is stored locally in your browser.

Features

  • Non‑School Day (NSD): Mark a date as NSD via the Pending ▾ menu. Attendance is disabled and excluded from aggregates.
  • Class Day Note (CDN): Add short notes for regular school days. Notes appear in remarks and exports.
  • Monthly Aggregates (Weekdays Only):
    • XCP Streak – Longest consecutive run of Absent, Cutting, or Pending
    • XCP Absent – Total Absent + Cutting + Pending
    • T Tardy – Total Tardy
    • E Excuse – Total Excuse
  • SF2 PDF Export: Generates quick School Form 2 (weekdays only) for the selected month with fill‑in school metadata.
  • Storage Meter: Shows browser storage usage with warnings when nearing limits.
  • Scrollable Tables: Student & attendance tables scroll independently with sticky headers.
  • Row Selection: Click a row to highlight and jump directly to that student.
  • Swipe & Keyboard Navigation: Navigate students using swipe gestures, on‑card arrows, or ← →.

Quick Start

  1. Create or load a class.
  2. Add students using Last, First Middle format and select Sex.
  3. Select a date and mark attendance using status buttons.
  4. Use ▾ next to Pending to set or cancel NSD.
  5. Add optional Class Day Notes for school days.

Import & Export

  • Import CSV: Recommended format with columns: Class, Student, Sex, Status, Date, NSDReason, DayNote
  • Class CSV Export: Select one or more dates → one combined CSV (supports NSD & CDN).
  • Student CSV Export: Available in Edit mode; exports history excluding PENDING.
  • SF2 PDF Export: Exports the full month (weekdays only). Current month is capped at today.

Tips & Notes

  • Dates work best in ISO format YYYY‑MM‑DD.
  • Avoid re‑saving CSVs in Excel to prevent date shifting.
  • Data is device & browser specific. Always export backups.
  • Locked mode disables editing until a valid license is registered.
