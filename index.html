Overview

ClassTapMark helps you manage classes, add students, and record daily attendance with quick status buttons. Data is stored in your browser via localStorage, so it’s device & browser‑specific.

Quick Start

  1. Create a Class with 📚 Create Class. Then use Load Class.
  2. Add Students using the format: Last Name, First Name Middle Name. Set Sex: Male / Female and click Save
  3. Mark Attendance—pick a date, navigate students (⏪ ◀ ▶ ⏩), and choose a status: Present, Absent, Tardy, Cutting, Excuse, Pending.
  4. Import .csv with columns: "Class","Student","Sex","Status","Date".
  5. Export CSV:
    • Class export (📥 Export CSV): choose one or multiple dates → downloads one CSV.
    • Student export (while editing): downloads that student’s full history excluding PENDING.

Import Tips

  • Recommended: Use CSV for imports. Keep the Date column as text in YYYY‑MM‑DD.
  • Import only the exported CSV...
  • Don’t reopen CSV in Excel just to check it—use a text editor to avoid date re‑parsing or do not save changes made in Excel.

FAQ

  • Date picker format not YYYY-MM-DD. Change your OS short date to ISO 8601.
  • Why is the Date a number in my sheet? That’s an Excel serial date; the importer understands it and converts it to YYYY‑MM‑DD.
  • My imported dates shifted one day back. Caused by time‑zone conversion with date‑only values. Best: stick to CSV.
  • How do I delete a student & their attendance? Click 🗑️. The app removes the student and purges their attendance records.
  • Reset everything? Delete classes or clear site data (this wipes localStorage). Export first if you need a backup.
  • Why is Export disabled? Click ✏️ Edit on a student to enable the student export. Class export uses the main 📥 Export CSV button.
  • Where is data stored? Browser localStorage on this device only.
  • Combine multiple dates? Yes—select multiple dates in the Export modal; one combined CSV will be generated.
